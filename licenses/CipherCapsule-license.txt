The complete application source, local editor integration, dependency lock files, signed libsodium archive, editor npm archives and TinyMCE upstream preferred source archive are supplied under Source.
TinyMCE upstream source: vendor/tinymce-source-8.10.0.tar.gz, tag 8.10.0, https://github.com/tinymce/tinymce
Build application: install .NET SDK version in global.json, Python 3 and Node.js on PATH, then run python scripts/build.py from Source. The verifier checks the pinned libsodium hash and official minisign signature; editor archives are checked against pinned npm SHA-512 integrity values. Viewer is published first, embedded into Builder, then Builder is published. No SDK, Node.js or Python is needed by recipients. The upstream editor source archive includes its own build scripts and dependency files.

Fixed dependencies: libsodium 1.0.22-stable snapshot (official signed 2026-10-15 archive); Microsoft.Web.WebView2 1.0.4258.31; AngleSharp 1.8.5; TinyMCE 8.10.0; tinymce-i18n 26.10.19.
